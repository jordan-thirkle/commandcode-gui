## [0.1.0] - 2026-08-07

### Added
- Native Electron + React + TypeScript desktop GUI for Command Code.
- Drives the real CLI via the documented NDJSON output stream (no private protocol).
- Chat view with live token/tool/sub-agent streaming.
- Session list/resume + transcript view.
- Gauntlet Studio: define → split → fan out builders → critic → iterate.
- Skills & custom agents browse; MCP server status.
- Model/effort picker with DUSTLINE routing conventions.
- Static SEO-optimized marketing site in `site/`.
- Vitest suite (bridge parser, command builder, gauntlet state machine, critic parsing).
