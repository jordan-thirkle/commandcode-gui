Get started

Install & quickstart

Get the Command Code GUI running on your machine in a few minutes. Everything runs locally — no account, no cloud.

Requirements

Node.js 22+

The app (and the Command Code CLI) run on Node 22 or newer. Check with node --version.

Command Code CLI

Install the coding agent it wraps: npm i -g command-code. The app finds it automatically.

An authenticated account

Log in once with cmd login (or the Command Code Studio) so runs have credentials.

Two-command setup

Clone the repository

git clone <your-repo-url> commandcode-gui
cd commandcode-gui

Install dependencies

npm install

Run

npm run dev    # terminal 1 — Vite dev server (localhost:5173)
npm start       # terminal 2 — opens the Electron window

Or run the production build

npm run build     # typecheck + compile main + renderer
npx electron .    # loads the built app

First run

Chat pane

Type a prompt and press Run. The app streams the assistant's text, thinking, tool calls, and sub-agent progress live, and reports token usage in the footer.

Sessions

Open the Sessions view to browse your real session catalog, read transcripts, and resume any conversation.

Gauntlet Studio

Define an artifact and a reference bar, split it into systems, and run the loop. The board shows builder status, check results, and critic verdicts per round.

Model picker

Switch presets in the header. The default is deepseek/deepseek-v4-pro at effort high — switch to the quality-critical or bulk tier as the task demands.

Troubleshooting

The window opens but is blank

In dev mode the renderer needs the Vite server on localhost:5173. Start it with npm run dev before npm start.

Runs drop into a shell instead of the agent

On Windows, cmd can resolve to the system shell. The app resolves the real CLI automatically — make sure the CLI is installed via npm i -g command-code so the npm global path is findable.

I see "Not authenticated" errors

Run cmd login once in a terminal. The GUI uses the CLI's existing credentials.

Where are my sessions stored?

In the standard Command Code location, ~/.commandcode/projects/. The app reads that catalog directly — it does not duplicate it.
