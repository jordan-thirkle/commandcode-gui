Why a GUI over the CLI?

Terminals are great for one task at a time. Long-running agent workflows — fan-out builds, screenshot reviews, multi-round critique — need a board, not a scrollback.

See the whole loop at once

Tool calls, sub-agents, token usage, verdicts, and round history render as a board instead of a wall of text.

No terminal babysitting

A session persists on disk. Close the app, come back, resume exactly where you left off.

Built on the real engine

It drives the actual Command Code CLI via the documented JSON stream — no forked engine, no private protocol, forward-compatible by design.

Get running in two commands

Frequently asked questions

What is Command Code GUI?

It is a free, open-source desktop application (built with Electron and TypeScript) that wraps the Command Code coding agent CLI in a native graphical interface. It adds a chat pane, session management, MCP server status, a skills and agents browser, and a Gauntlet Studio for AI-driven game development.

Is it a fork of Command Code?

No. It drives the real, installed Command Code CLI through its documented headless JSON protocol (cmd -p --output-format json). There is no forked engine and no private protocol, so it stays compatible with CLI updates.

What is the Gauntlet Studio?

It productizes the Gauntlet Loop — a game development workflow where you split work into independent systems, fan out builder agents with isolated file ownership, run automated checks, and grade the real rendered output with a separate harsh critic agent before iterating.

Does it work on macOS?

The app is Windows-first but macOS-ready. The Electron + TypeScript stack is cross-platform, and the CLI bridge resolves the command executable platform-independently.

Do I need to install anything else?

Yes — you need the Command Code CLI (npm i -g command-code) and Node.js 22 or newer. The app finds the CLI automatically, even on Windows where the system shell shadows the cmd name.
